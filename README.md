هندسة أنظمة الذكاء الاصطناعي التوكيلي المتقدمة:


فكرة المشروع:
Rafeeq Mini هو مشروع تدريبي عملي لتعلّم بناء أنظمة Agentic AI بطريقة آمنة ومنظمة.
المشروع يحاكي وكيل دعم لخدمات التوصيل يستطيع التعامل مع سيناريوهات مرتبطة بالطلبات والعملاء، مع التركيز على:
•	بناء وكيل AI محدود الصلاحيات.
•	استخدام الأدوات بطريقة منظمة.
•	حماية هوية العميل والموافقات.
•	مراقبة سلوك الوكيل وتسجيل الأدلة.
•	اختبار الحالات المختلفة.
•	تجهيز المشروع ليكون قابلاً للتشغيل والمشاركة.
المشروع مصمم كمختبر تدريبي تراكمي لمدة 3 أيام، وينتقل تدريجيًا من المعمارية والأدوات إلى الأمان والمراقبة والتجهيز النهائي



طريقه التشغيل :


1-فتح المشروع
يمكن تشغيل المشروع من خلال Google Colab أو بيئة Python مناسبة.
المشروع مصمم ليعمل باستخدام:
•	Python
•	Python Standard Library
•	LLM_MODE=stub
•	Matplotlib بشكل اختياري
ولا يحتاج إلى API Key.
________________________________________
2. تشغيل الخلايا بالترتيب
افتح ملف:
Rafeeq_Mini_Capstone.ipynb
ثم شغّل الخلايا بالترتيب من الأعلى إلى الأسفل.
لا انتقل إلى التمرين التالي قبل التأكد من أن الخلية الحالية تعمل بنجاح.
________________________________________
3.يتم تشغيل بيئة Stub
المشروع يستخدم نمط تشغيل حتمي وغير متصل:
LLM_MODE = "stub"
ثم يتم ضبطه في البيئة:
os.environ["LLM_MODE"] = LLM_MODE
هذا يعني أن المشروع التدريبي لا يعتمد على اتصال فعلي بخدمة LLM خارجية.
________________________________________
4.افحص البيئة
ابدأ بخلية:
C0_ENV_DOCTOR
وظيفتها التحقق من:
•	إصدار Python.
•	توفر الملفات.
•	المساحة المتاحة.
•	ملفات المختبر.
•	إعداد التشغيل المطلوب



طريقة استخدامي للمشروع :

نفّذ فقط التمارين المرقمة والمطلوبة داخل الـ Notebook.

•	نجاح الاختبارات.

•	رسائل النظام.

عند الوصول إلى بوابة كل يوم، احفظ JSON evidence الناتج من التمرين.
